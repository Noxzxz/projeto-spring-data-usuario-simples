====================================================================
1. INICIAR O BANCO DE DADOS E A API (DOCKER)
====================================================================

Passo 1.1: Abra o PowerShell na pasta raiz do projeto
    cd "C:\Users\ihan.nunes\OneDrive - ESPM\Documentos\AulaPOO\projeto-spring-data-usuario-simples"

Passo 1.2: Suba os containers do Docker
    docker compose up -d

    Isso vai iniciar:
      - PostgreSQL (porta 5432)
      - Spring Boot API (porta 8080)
      - pgAdmin (porta 5050)

Passo 1.3: Aguarde os containers ficarem saudaveis (cerca de 30s)
    docker ps

    As colunas STATUS devem mostrar "healthy" para o postgres e "Up" para os demais.


====================================================================
2. INICIAR O FRONTEND ANGULAR
====================================================================

Passo 2.1: Abra um NOVO cmd (Prompt de Comando)

Passo 2.2: Navegue ate a pasta do Angular
    cd "C:\Users\ihan.nunes\OneDrive - ESPM\Documentos\AulaPOO\projeto-spring-data-usuario-simples\ead-platform\ead-platform"

Passo 2.3: Instale as dependencias (apenas na primeira vez)
    npm install

Passo 2.4: Inicie o servidor de desenvolvimento Angular
    npx ng serve

    Aguarde a mensagem: "√ Application bundle generation complete"
    Isso leva cerca de 30 segundos na primeira vez.

Passo 2.5: O Angular estara disponivel em:
    http://localhost:4200

4. COMANDOS UTEIS
====================================================================

Verificar containers rodando:
    docker ps

Parar os containers:
    docker compose down

Ver logs da API:
    docker logs usuario-api-app

Reconstruir a imagem Docker (se alterar o codigo):
    docker compose build
    docker compose up -d

Rodar sem Docker (usando H2 em memoria - mais rapido):
    mvn spring-boot:run
    (acessar em http://localhost:8081)

====================================================================
6. SOLUCAO DE PROBLEMAS
====================================================================

ERRO: "Port 8080 already in use"
    -> Outro processo esta usando a porta. Execute:
       netstat -ano | findstr :8080
       Depois mate o processo com: Stop-Process -Id <PID> -Force

ERRO: "Cannot load driver class: org.postgresql.Driver"
    -> O Docker com PostgreSQL nao esta rodando. Execute:
       docker compose up -d

ERRO: "npm nao e reconhecido"
    -> Instale o Node.js em: https://nodejs.org

ERRO: "ng nao e reconhecido"
    -> Execute: npm install -g @angular/cli
    -> Ou use: npx ng serve

API retornando 404:
    -> Verifique se as rotas estao corretas no Swagger:
       http://localhost:8080/swagger-ui.html
